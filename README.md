# 🌱 Pupuk Organik POC – Tani Makmur  
Website promosi dan penjualan Pupuk Organik Cair (POC) produksi Tani Makmur, Sendang – Senori – Tuban.  
Website ini dibuat untuk memudahkan pelanggan melihat informasi produk dan melakukan pemesanan langsung melalui WhatsApp.

---

## 📌 Fitur Website
- Tampilan modern & responsif  
- Informasi lengkap tentang Pupuk Organik POC  
- Galeri gambar produk  
- Tombol pesan langsung via WhatsApp  
- Struktur ringan dan cepat diakses  
- Siap dipublikasi ke GitHub Pages, Netlify, Vercel, dll
